# Multi-Vendor E-Commerce (MERN)

Multi-vendor e-commerce application with React client, Express API, and Socket.io.

## Structure

- `client/` — React frontend
- `server/` — Express backend API
- `socket/` — Real-time socket service

## Run locally

1. Copy `.env` files into `client/`, `server/`, and `socket/` (see each folder).
2. From the project root:

```bash
docker-compose up
```

Or run each service with `npm install` and `npm run dev` in its folder.
